
# Funcionament del joc

## Pantalla inicial
El jugador escriu el seu nom i prem Començar.

## Categories
Pot escollir entre Esports i Menjar.

## Preguntes
Cada categoria conté 3 preguntes.
Cada pregunta té 4 opcions.

## Temporitzador
El jugador té 15 segons per respondre.
Si no respon, la pregunta es considera fallada.

## Resultats
Es mostra el nombre de respostes correctes.

## Tornar a jugar
El botó Tornar a jugar retorna a la pantalla
de categories i conserva el nom del jugador.
La puntuació es reinicia a zero quan comença
una partida nova.

## Sortir
El botó Sortir torna a la pantalla inicial
i esborra el nom del jugador.
