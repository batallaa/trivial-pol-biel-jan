
# Trivial - Pol, Biel i Jan

## Descripció
Joc web de preguntes tipus Trivial desenvolupat
amb HTML, CSS i JavaScript.

## Integrants
- Pol Hernández
- Biel Batalla
- Jan Fernández

## Objectiu
Crear un joc amb dues categories de preguntes,
temporitzador, puntuació i opció de tornar a jugar.

## Funcionalitats
- Introduir nom del jugador
- Escollir categoria: Esports o Menjar
- Respondre 3 preguntes
- Temporitzador de 15 segons per pregunta
- Mostrar resultat final
- Tornar a jugar o sortir

## Tecnologies
HTML5, CSS3, JavaScript i GitHub.

## Organització
- main: versions estables
- test: integració i proves
- dev-pol: inici i categories
- dev-biel: preguntes i temporitzador
- dev-jan: disseny i resultats
