
# Planificació del Trivial

## Equip

## Requisits
1. Demanar nom del jugador.
2. Mostrar una salutació personalitzada.
3. Permetre escollir Esports o Menjar.
4. Mostrar 3 preguntes amb alternatives.
5. Validar les respostes.
6. Limitar cada pregunta a 15 segons.
7. Mostrar encerts al final.
8. Permetre tornar a jugar o sortir.
9. Adaptar el disseny a mòbil.
